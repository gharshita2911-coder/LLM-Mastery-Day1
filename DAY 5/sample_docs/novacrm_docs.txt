NovaCRM – Technical Documentation v3.2

OVERVIEW
NovaCRM is a cloud-based customer relationship management platform designed for B2B sales teams. It supports up to 500,000 contacts per account and integrates natively with Gmail, Outlook, Slack, and Salesforce.

SYSTEM REQUIREMENTS
NovaCRM runs entirely in the browser. Supported browsers: Chrome 110+, Firefox 115+, Edge 110+. Safari is not officially supported. Minimum internet speed recommended: 10 Mbps. No desktop installation is required.

AUTHENTICATION
NovaCRM uses OAuth 2.0 for authentication. Single Sign-On (SSO) is available on Enterprise plans via SAML 2.0. Two-factor authentication (2FA) is mandatory for all admin accounts and optional for standard users. Session tokens expire after 8 hours of inactivity.

API RATE LIMITS
The NovaCRM REST API enforces the following rate limits:
- Free tier: 100 requests per hour
- Starter plan: 1,000 requests per hour
- Professional plan: 5,000 requests per hour
- Enterprise plan: 20,000 requests per hour
Requests exceeding the limit return HTTP 429. A Retry-After header indicates when to retry.

DATA EXPORT
Users can export contact data as CSV or JSON from Settings > Data Management > Export. Exports are limited to 50,000 records per file. For larger exports, the bulk export API endpoint (/api/v2/export/bulk) must be used. Exported files are available for download for 24 hours after generation.

WEBHOOKS
NovaCRM supports outbound webhooks for the following events: contact.created, contact.updated, contact.deleted, deal.won, deal.lost. Webhooks use HTTPS POST with a JSON payload. A shared secret is used to verify webhook authenticity via HMAC-SHA256 signature in the X-NovaCRM-Signature header.

PRICING
Free tier: Up to 2 users, 1,000 contacts, core CRM features.
Starter: $29/user/month – up to 10,000 contacts, email integration.
Professional: $79/user/month – up to 100,000 contacts, API access, automation.
Enterprise: Custom pricing – unlimited contacts, SSO, dedicated support, SLA.
All paid plans include a 14-day free trial. Annual billing offers a 20% discount.

SUPPORT
Standard support (email, 48h response) is available on all paid plans. Priority support (4h response, live chat) is included in Professional and Enterprise plans. A dedicated Customer Success Manager is assigned to Enterprise accounts.
